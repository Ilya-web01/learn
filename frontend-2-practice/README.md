# Практическая работа 2 



## Запуск

Откройте `index.html` в браузере или через Live Server. 

## Реализовано

- Текущая дата выбрана при открытии страницы, слоты сразу показаны.
- Переключение дней обновляет список слотов и сбрасывает время.
- Выбор свободного слота обновляет нижнюю панель.
- Стрелки переключают месяцы, прошлые даты заблокированы.
- Нижняя панель показывает день недели, дату, год и выбранное время.
- Кнопка «Далее» активна после выбора свободного времени и показывает подтверждение.
