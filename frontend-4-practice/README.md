# Практическая работа №4 — Nurth Cut



## Запуск

Нужен Node.js и npm. Откройте терминал в `frontend-4-practice`:

```bash
npm install
npm run dev
```


Сайт: http://localhost:3000/

## Что проверять

1. При запуске отображается «Загрузка…», затем календарь на месяце, который вернул сервер.
2. При смене даты показывается «Загрузка слотов…», затем доступные часы. Выбранное время сбрасывается.
4. При быстром переключении дней старые запросы отменяются через `AbortController`, а ответ сверяется с датой.
