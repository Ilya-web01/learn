# Выбор даты и времени — барбершоп

Учебная вёрстка одной страницы по макету записи клиента.

## Как открыть

Откройте `index.html` в браузере. Интернет и установка зависимостей не нужны.

## Файлы

- `index.html` — семантическая разметка.
- `styles.css` — внешний файл стилей, Flexbox и CSS Grid, адаптивная вёрстка, hover-состояния.
- `script.js` — необязательная для задания интерактивность выбора даты и свободного времени.
- `images/` — папка для изображений, если понадобятся.

## Что реализовано

- Календарь июня 2026 и выделение выбранного дня.
- Сетка времени с визуально занятыми и свободными слотами.
- Реакция на наведение, курсор-указатель и доступные состояния фокуса.
- Кнопка «Далее», активная после выбора свободного времени.

Доступность времени показана на демонстрационных данных и не связана с сервером. Дизайн основан на учебном макете, показанном на скриншоте.
