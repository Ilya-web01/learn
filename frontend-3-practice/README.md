# Практическая работа №3 — React + Vite



## Запуск

Нужен Node.js. В терминале папки проекта:

```bash
npm install
npm run dev
```
## Проверка

При загрузке выбран сегодняшний день. При выборе дня слоты обновляются, время сбрасывается. Время отображается в нижней панели. Месяцы листаются стрелками; прошедшие даты недоступны. Кнопка «ДАЛЕЕ» активируется после выбора времени.
